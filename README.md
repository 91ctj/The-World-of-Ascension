# 登神阶 · 世界观档案

一个为《登神阶》世界观制作的单页介绍网站。以“神圣档案”为视觉概念，用墨黑、鎏金与羊皮纸色呈现元力、魂环、神位与万年史诗。

## 打开方式

直接双击 `index.html` 即可在浏览器中阅读。无需安装依赖，也不依赖外部图片或字体服务。

如果希望用本地服务器预览：

```powershell
python -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 公网分享

当前公网预览使用 Cloudflare Quick Tunnel 发布：地址每次重启后可能变化，并且需要本机保持开机、本地服务与隧道进程持续运行。若需要长期固定网址，建议把本文件夹拖入 Netlify Drop，或部署到 GitHub Pages。

## 页面结构

- **序章**：世界观主视觉与核心数字
- **01 世界基石**：元力、魂力、灵魂、魂器、魂环、魂核
- **02 力量体系**：魂师九环、魂兽五境、神选 / 半神 / 神、十二属性、最佳魂环配置
- **03 万年史诗**：龙族时代、龙陨纪元、天使纪元、神佑纪元
- **04 势力版图**：武魂殿、金鹄帝国、玄霜帝国、杀戮之都、神界
- **05 光与影**：天使信仰的明面与被涂抹的真相
- **06 群像**：八位核心人物档案，可筛选、点击查看详情
- **07 故事**：《登神阶：魔裔天使》三幕结构与血脉谱系
- **尾声**：神佑纪元

## 交互

- 顶部导航滚动高亮、阅读进度条
- 魂师 / 魂兽体系切换，点击境界查看详情
- 四个历史纪元切换
- 势力地图光点与势力卡片联动
- “揭开神谕”真相揭示
- 人物筛选与档案弹窗
- 移动端折叠导航、响应式布局
- 支持 `prefers-reduced-motion`
